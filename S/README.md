# 🎓 Student Polling and Survey System

## 📌 Overview

The Student Polling and Survey System is a web-based platform that allows educational institutions to create, manage, and analyze surveys on academic and campus-related topics. It enables students to participate easily while helping administrators collect feedback efficiently.

## 🚀 Features

* Create and manage surveys
* Student participation in polls
* Real-time data collection
* Easy-to-use interface
* Centralized feedback system

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: PHP
* Database: MySQL

## 📂 Project Structure

```
project-folder/
│── feedback_form.php

```

## ⚙️ Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/student-polling-system.git
   ```

2. Move the project to your server directory (e.g., XAMPP `htdocs`)

3. Import the database:

   * Open phpMyAdmin
   * Create a new database
   * Import the `.sql` file

4. Start Apache and MySQL from XAMPP

5. Open in browser:

   ```
   http://localhost/student-polling-system
   ```

## 📸 Usage

* Admin creates surveys
* Students fill out the forms
* Responses are stored and analyzed
